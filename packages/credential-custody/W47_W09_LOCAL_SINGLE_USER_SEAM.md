The current W47 source CORS-disabled means 4399->47182 browser fetch has to be explicitly designed; prefer a same-origin controlled reverse proxy **or** narrowly scoped credentialed CORS, not wildcard access.
2. Session proves **local app interaction only**, not any social platform account. Do not make an enterprise OAuth/SSO/user database.
