## 1. 唯一产品定位：私人、开源、本机优先、简单

言策只服务开发者自己和朋友，每位朋友可在自己的电脑安装和使用。**没有开发者购买的集中服务器，也不要求朋友连接开发者电脑**；使用云端模型供应商的 API 不等于自建共享服务器。
不建设企业 SaaS、多租户管理平台、企业 RBAC、中央注册体系、复杂身份审批、设备配对平台、额外发布签署平台或为每个 Bug 新建的发布工程。
体验优先：安装简单、打开即用、原始 B＋C 聊天优先、一个闺蜜大脑、一个原 Composer、同一可复用更新路径。252 稳定能力 ID（含 100 UIE）只用于追踪，不等于已经完成 252 个能力，也不代表要写 252 套系统。

### 1A. 唯一底座：Agno/AgentOS（2026-10-28 用户再次确认）

**新言策以官方 Agno/AgentOS 为智能体及模型执行底座，不是以 ChatterMate 为整体底座的项目。** Agno 负责私人 AI 智能体、模型执行、原生 Session/Run/ChatHistory 与工具调度。ChatterMate 仅是旧项目及部分既有可复用业务组件的来源之一；经兼容性核对后可复用其聊天界面、AIConfig、联系人、消息等成熟部分，但**不得要求先恢复完整 ChatterMate 或取得旧项目 Owner 审签才能上线 Agno 功能**。

选择模型 → 保存配置 → 实际 Agno Run → 返回回答和历史，是首要真实用户流程。优先复用现有 Agno/AgentOS、配置与原生持久化，不自研第二模型路由器、模型引擎或历史库；确有缺口时使用成熟组件和薄适配。旧集成组件阻断用户功能时只修接线，不升级为平台级架构重建。

## 2. 普通本地使用：没有终端配对门槛

用户使用言策本身、闺蜜大脑、普通 AI 聊天、翻译、历史查阅，不需要输入终端 `pair`、复制 64 位配对码，不需要每 5 分钟重新登录，不需要安装本地模型，更不需要复杂技术配置。
既有 W47 `local-operator-console.mjs` 和 W46 `BCLocalSessionConnector.vue` 的终端配对流程属于历史工程实现，**不得作为最终用户普通使用的必需步骤**。W47/W46 在原有运行时与 UI 中做最小纠偏，不新增第二套登录或认证系统。
正常启动、API 可达性、必要的内部请求边界由应用自身处理，用户界面不暴露开发终端指令。本条不授权将个人社交帐号、真实发送或私密数据接口无条件暴露给任意第三方网页。只保留能自动执行、不会增加用户操作负担的必要接口边界和现有必要保障。
未接通真实私人 Agno/ChatHistory 时只能显示真实不可用状态，不能以配对界面或假消息代替功能。

## 4. 单一闺蜜大脑与真实聊天

原有 Agno 是唯一私人助手：真实问答、持续多轮、保存和重启恢复原生 ChatHistory、切换模型后继续相应线程、允许调用言策既有工具/功能、支持翻译、来源真实的 0–3 条候选（不足不伪造）。
原 B＋C 保持聊天优先：PRIVATE 脑使用原定入口，CONTACT 聊天只有一个 Composer；不新增重复侧栏、第二个发送器、重复的助手窗格。
真人联系人自动托管可按全局或指定联系人开启；用户仅查看/切换/聚焦不接管。对 A 真实输入/粘贴/附件等编辑才人工接管 A，B/C 有效托管继续独立运行。

## 6. 轻量交付：源码通过不等于用户使用

四个状态必须严格分开：
- `SOURCE_PASS`：准确源码 SHA、构建和范围内测试通过；仅关闭开发子任务。
- `STATIC_WEB_DELIVERY_PASS`：同一固定地址已真实更新、浏览器验证资源及回滚；不代表完整业务。
- `INTEGRATED_STAGING_PASS`：Web/API/相应 AI 和授权等真实功能在非生产环境通过；未实现能力仍 HOLD。
