# 言策 V2｜最高产品与执行规则（2026-10-26）

**规则级别：PROJECT_HIGHEST_PRODUCT_EXECUTION_RULE — 用户亲自确认。**
**生效范围：** 言策 V2 产品定位、UX、现有 Agno/模型接入、业务集成、源码 Owner 协作、非生产验收、更新回滚与用户交付。
**权威位置：** 本文件 `docs/PROJECT_HIGHEST_EXECUTION_RULE.md` 是唯一规范正文；根目录 `AGENTS.md` 仅为入口索引，其他交接只能引用本文件。
**优先顺序：** 本规则优先于此前与其相冲突的产品草案、窗口派工、开发便利性假设和旧版复刻惯例；不推翻法律/许可、用户本人对真人消息和费用的授权边界、已证明的账户隔离/防误发送约束、Git 分支保护或相应独立源码维护职责。历史记录保留，不得改写为虚假 PASS。
**变更控制：** 仅用户新的明确决定可改变上述产品目标；视窗9-2统一更新规则及 Owner 差异，不因用户一句补充就分发一批重复指令。执行前先核对最新 SHA/已完成项，避免与既有并行开发冲突。

## 1. 唯一产品定位：私人、开源、本机优先、简单

言策只服务开发者自己和朋友，每位朋友可在自己的电脑安装和使用。**没有开发者购买的集中服务器，也不要求朋友连接开发者电脑**；使用云端模型供应商的 API 不等于自建共享服务器。
不建设企业 SaaS、多租户管理平台、企业 RBAC、中央注册体系、复杂身份审批、设备配对平台、额外发布签署平台或为每个 Bug 新建的发布工程。
体验优先：安装简单、打开即用、原始 B＋C 聊天优先、一个闺蜜大脑、一个原 Composer、同一可复用更新路径。252 稳定能力 ID（含 100 UIE）只用于追踪，不等于已经完成 252 个能力，也不代表要写 252 套系统。

## 2. 普通本地使用：没有终端配对门槛

用户使用言策本身、闺蜜大脑、普通 AI 聊天、翻译、历史查阅，不需要输入终端 `pair`、复制 64 位配对码，不需要每 5 分钟重新登录，不需要安装本地模型，更不需要复杂技术配置。
既有 W47 `local-operator-console.mjs` 和 W46 `BCLocalSessionConnector.vue` 的终端配对流程属于历史工程实现，**不得作为最终用户普通使用的必需步骤**。W47/W46 在原有运行时与 UI 中做最小纠偏，不新增第二套登录或认证系统。
正常启动、API 可达性、必要的内部请求边界由应用自身处理，用户界面不暴露开发终端指令。本条不授权将个人社交帐号、真实发送或私密数据接口无条件暴露给任意第三方网页。只保留能自动执行、不会增加用户操作负担的必要接口边界和现有必要保障。
未接通真实私人 Agno/ChatHistory 时只能显示真实不可用状态，不能以配对界面或假消息代替功能。

## 3. 模型来源：云端独立可用，本地完全可选

没有本地 Qwen3、Ollama、llama.cpp 或任何模型的朋友电脑，**只要配置一个真实可用的云端 AI 来源，就必须能使用闺蜜大脑**。
首选支持复用用户自有的 OpenRouter API Key；允许合法 OpenAI API 来源。ChatGPT 官方登录/订阅是独立资格，只有真实受支持的官方接入方式和使用权限已核验时才启用，**不得假定 ChatGPT 订阅自动授予 OpenAI API 调用**。
本地 Qwen3/llama.cpp 是额外可选来源：检测不到时跳过，不得让整款软件因本地模型缺失而不可用；检测到可按用户选择使用。
统一复用**原有官方 Agno/AgentOS** 一个脑、同一原生对话历史和工具能力，不因模型而创建第二个 Agent、历史库、Composer 或发送器。
现有 W43、W45、W46 对 `qwen3:8b` / `LLAMACPP_LOCAL_QWEN3_8B_FREE` 的专属要求须只在本地适配范围内生效；合法的云端 Agno 来源回执必须能够进入同一翻译/候选/Composer 契约，仍保留真实 Run、Session、MID、来源和权限验证。
首次没有配置模型时，只显示简单配置界面；以后复用设置。模型不可用时明确报错并允许选择已有来源。未经用户明确配置/同意，不偷偷切换到另一个收费模型。
云端 API 密钥由每个朋友在自己电脑保存，调用费用由用户所选供应商/套餐决定；不复制开发者密钥、不把密钥或支付信息写入公开前端、GitHub 或日志、不在未授权情况下发起收费测试。

## 4. 单一闺蜜大脑与真实聊天

原有 Agno 是唯一私人助手：真实问答、持续多轮、保存和重启恢复原生 ChatHistory、切换模型后继续相应线程、允许调用言策既有工具/功能、支持翻译、来源真实的 0–3 条候选（不足不伪造）。
原 B＋C 保持聊天优先：PRIVATE 脑使用原定入口，CONTACT 聊天只有一个 Composer；不新增重复侧栏、第二个发送器、重复的助手窗格。
真人联系人自动托管可按全局或指定联系人开启；用户仅查看/切换/聚焦不接管。对 A 真实输入/粘贴/附件等编辑才人工接管 A，B/C 有效托管继续独立运行。
任何 AI 模型都不因是“本地/云端”而获得自动向真人发消息的权限；真实外发通过 W24/W44/W25 既有唯一授权/撤销/Outbox/UNKNOWN 链路处理。

## 5. 原四平台与边界不变

保持 FB Personal `mautrix-meta`、FB Page `Pancake`（Chatwoot 既有受控备用）、WhatsApp `Baileys`、Telegram `TDLib JSON`，不得引入未经批准的第五平台或擅自替换已确认原生 SDK。
用户亲自连接自己的社交账户，选择是否开启自动托管，可随时停止。CONTACT A 不影响 B/C；GLOBAL 只作用于已授权目标范围。
W24 身份/Consent、W44 持久 Grant/Custody/Budget、W25 唯一 MessageDelivery/Outbox、授权撤销/过期、并发重复发送与 ACK/UNKNOWN 的有效防误发边界继续保留；这是业务必要性，不是企业管理功能。
没有真实账号和用户授权，测试只能 synthetic、不得主动登录账户、生成真实发送或将模拟 ACK 冒充平台 ACK。

## 6. 轻量交付：源码通过不等于用户使用

以固定可复用的非生产验收地址完成“旧版 → 新版 → 回滚”，检查实际运行 SHA/构建产物、JS 文件哈希、Service Worker、缓存、正常刷新与强刷、浏览器点击截图、Web/API 正确 JSON、CORS/身份边界（若该候选包含 API）。
静态演练一旦证明可靠，就冻结并重复使用，不再研发新的发布平台、Trusted Publisher、管理员计划任务、新签署机构或每次 Bug 重走的流程。
四个状态必须严格分开：
- `SOURCE_PASS`：准确源码 SHA、构建和范围内测试通过；仅关闭开发子任务。
- `STATIC_WEB_DELIVERY_PASS`：同一固定地址已真实更新、浏览器验证资源及回滚；不代表完整业务。
- `INTEGRATED_STAGING_PASS`：Web/API/相应 AI 和授权等真实功能在非生产环境通过；未实现能力仍 HOLD。
- `USER_DELIVERED`：获对应发布许可后用户在其实际访问地址看见目标 SHA，并完成该问题真实验收；不可由前面三个状态自动升级。
旧版言策“代码修了、浏览器仍旧版、API 回 HTML200、跨版本 CORS 错、不能回滚”的失误禁止复现。用户可见的功能修复未交付前不得报 CLOSED。
Windows IPC/Tauri/WebView2 仅在桌面独有能力实际需要时处理，**不构成 Web 更新的前置阻断**。不应将真实的 Web 更新交付变成漫长的安全审批开发项目。

## 7. 一次统筹、原 Owner 自治，禁止逐条反复派工

总协调 **W09-2／黑茶**：先同步 Windows/GitHub 最新实际 Owner SHA、PR/CI、运行版本与交接；核对已实现功能后只针对真实缺口作最小差异派工；统一回执，不要求用户几分钟内转发多个版本指令。
源 Owner 继续控制原作用域：W43 Agno/模型/原生 History，W45 翻译/来源候选，W46 B＋C/唯一 Composer/UI，W47 原 API/runtime，W24/W44/W25 现有授权/托管状态/唯一发送，W30 已有 CI；W23/W26–W29 原媒体与渠道职责不变。
不重建已有 CI、登录体系、授权体系、数据库、Agent、消息发送器；不抢写他人工作树，不覆盖原已签署源码，不自动合并未审核的 Draft PR。用户要求新特性时由 W09-2 归并为**一份**差异计划，先查是否已做，只有有实际失败才再修。

## 8. 必须完成的最小真实产品验收

A. 开发者电脑有 Qwen3：打开言策普通聊天直接可用，并能手动选已配置云端模型；无终端配对。
B. 朋友电脑零本地模型：自己配置 OpenRouter 合法 API Key，能使用真实 Agno 多轮聊天、重启恢复历史、翻译、合格的回复建议，不显示本地模型未安装的阻断。
C. 无任意 AI 来源：正常启动，简单提示配置；不伪造回复、不要求配对码或下载本地模型。
D. 四平台真实权限：用户明确授权才连接/托管，A 人工接管不影响 B/C，其它渠道按既有资格规则；未授权不得外发。
E. 固定地址更新与回滚：真实用户浏览器看到实际新资源、通过指定功能验收，有问题可恢复旧版。
每项未证实真实运行及截图/日志/准确 SHA 只能标 `HOLD`，不能拿 source pass、fixture、历史测试或截图替代当前版本。

## 9. 强制执行与当前实现差异

此规则是**目标和执行决策**，不是宣称既有代码已完全做到。现有强制终端配对、Qwen3 硬编码、缺乏已证实的云端 Agno 原生路径、未具备真实 PRIVATE ChatHistory 的版本，必须登记实际差距并由原 Owner 最小纠偏；不得偷偷删掉安全校验或生成假的 PASS。
已有 2026-10-26 固定 Web 地址 127.0.0.1:44751 的 C→B→C 实际更新/回滚证据可继续继承，不允许倒退成“从未部署”，但该 Web 更新不代表私人闺蜜大脑已经真实可用。具体版本证据应放在独立验收回执而非反复改本政策。
总交付为一份视窗9-2汇总：当前 SHA、完成项、真正源码缺口、用户端云端无本地模型验收、真实 Agno/历史、普通打开无配对、社交外发安全、浏览器版本和回滚状态、准确 HOLD Owner。
